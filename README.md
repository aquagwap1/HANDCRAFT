# HANDCRAFT

HANDCRAFT — веб-платформа для продажи изделий ручной работы. Мастера размещают свои товары, а покупатели находят изделия и оформляют заказы.

## Цель проекта

Создать маркетплейс, который обеспечивает полный цикл взаимодействия между покупателем и мастером:

1. Мастер регистрируется и размещает товар.
2. Покупатель находит товар в каталоге.
3. Покупатель добавляет товар в корзину и оформляет заказ.
4. Мастер получает заказ и изменяет его статус.
5. Покупатель отслеживает состояние заказа.

Онлайн-оплата в первой версии не предусмотрена.

## Технологический стек

| Технология | Назначение |
|---|---|
| JavaScript | Основной язык разработки |
| React | Пользовательский интерфейс |
| Vite | Сборка и запуск frontend |
| Node.js | Серверная среда выполнения |
| Express | REST API |
| PostgreSQL | Реляционная база данных |
| Prisma | ORM и управление миграциями |

## Роли пользователей

- **Покупатель (BUYER)** — просмотр каталога, корзина, оформление и отслеживание заказов.
- **Мастер (SELLER)** — создание и управление собственными товарами, обработка заказов.
- **Администратор (ADMIN)** — блокировка пользователей и модерация товаров.

## Функции MVP

- Регистрация и авторизация.
- Каталог товаров с поиском по названию и категориями.
- Карточка товара с фотографией и описанием.
- Личный кабинет мастера.
- Создание, редактирование и скрытие собственных товаров.
- Корзина с товарами одного мастера.
- Оформление заказа без онлайн-оплаты.
- Просмотр и обработка заказов.
- Блокировка пользователей и модерация товаров администратором.

Дополнительные возможности будут рассматриваться после реализации MVP.

## Архитектура проекта

Проект разделён на две основные части:

- `client/` — frontend на React и Vite.
- `server/` — backend на Node.js и Express.

Backend организован по принципу разделения ответственности:

`routes → controllers → services → database`

Взаимодействие между frontend и backend выполняется через REST API. Данные хранятся в PostgreSQL, работа с базой осуществляется через Prisma.
