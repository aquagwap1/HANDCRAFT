# HANDCRAFT — дизайн-система

Документ описывает внешний вид сайта. Его будет использовать ИИ-агент при разработке frontend (React + Vite): цвета, шрифты, кнопки, карточки, поля и таблицы. Данные и права доступа берутся из `docs/architecture.md`. Экраны — в `docs/screens/`, каркасы — в `docs/wireframes/`.

## 0. Стиль

**Три слова о стиле:** светлый, природный, ремесленный.

**Главный цвет:** `#2E7D32` (зелёный). Он взят из первого прототипа сайта (ветка `old-prototype`, там зелёный акцент); тёмный оттенок выбран, чтобы белый текст на кнопках хорошо читался. Палитра сайта: зелёный, белый, чёрный.

**Примеры, которые вдохновили** (берём настроение, не копируем):

| Сайт | Что взяли |
|---|---|
| Etsy (etsy.com) | Крупные фото в карточках, сетка товаров и категории над каталогом |
| Ярмарка Мастеров (livemaster.ru) | Акцент на мастере и мастерской, тёплая подача авторских вещей |
| Kaspi Магазин (kaspi.kz) | Понятная таблица заказов и статусов в кабинете продавца |

## 3. Компоненты интерфейса (UI Components)

### Кнопки (Buttons)
Все кнопки имеют скругление углов `border-radius: 8px` (или `100px` для круглых/pill элементов) и плавный transition `150ms ease`.

- **Primary Button (Основная):**
  - Фон: `#2E7D32`
  - Текст: `#FFFFFF`, Inter Medium 14px
  - Состояние наведения: фон `#256628`
  - Применение: «Оформить заказ», «Добавить в корзину», «Найти», «Подтвердить».
- **Secondary / Outline Button (Второстепенная контурная):**
  - Фон: `transparent` (или `#FFFFFF`)
  - Рамка: `1px solid #E7E7E3`
  - Текст: `#191918`, Inter Medium 14px
  - Состояние наведения: фон `#F4F4F2`, граница `#B0B0A8`
  - Применение: «В корзину» (в каталоге), «В каталог», «Смотреть каталог».
- **Danger / Subtle Action (Отмена / Блокировка):**
  - Фон: прозрачный или светлый `#FEE2E2`
  - Текст: `#DC2626`, Inter Medium 13px
  - Применение: «Отменить», «Убрать», «Заблокировать».
- **Quantity Stepper (Степпер количества):**
  - Контейнер: рамка `1px solid #E5E7EB`, скругление `8px`, фоновый цвет `#FFFFFF`.
  - Кнопки `−` и `+`: ширина/высота 36×36px, центрированный текст, ховер на легкий серый фон `#F4F4F2`.
  - Значение: ширина 32px, центрированное начертание Inter SemiBold 14px.

### Поля ввода (Inputs & Controls)
- **Текстовые поля (Input, Textarea, Select):**
  - Высота: `44px` для стандартных полей (в строке поиска каталога `48px`).
  - Фон: `#FFFFFF`.
  - Рамка: `1px solid #E5E7EB`.
  - Скругление: `8px` (`rounded-lg`).
  - Внутренние отступы: `12px 16px`.
  - Типографика: Inter Regular 14px, цвет текста `#191918`, цвет плейсхолдера `#9CA3AF`.
  - Состояние фокуса: `outline: none; border-color: #2E7D32; box-shadow: 0 0 0 3px rgba(46, 125, 50, 0.15)`.
- **Подписи к полям (Form Labels):**
  - Inter Medium 12px / 13px, цвет `#374151`, с обязательным красным маркером `*` (`#DC2626`) для обязательных полей.

### Карточки и контейнеры (Cards & Surfaces)
- **Карточка товара в каталоге:**
  - Фон: `#FFFFFF`, рамка: `1px solid #EAEAEA`, скругление: `12px`, overflow: `hidden`.
  - Пропорция блока фото: `4:3` или `1:1`, плотная посадка (object-fit: cover).
  - Внутренний паддинг контентной зоны: `16px`.
  - Иерархия: Мелкая плашка категории (uppercase) → Название изделия → Мастерская → Цена в ₸ + статус наличия → Кнопка во всю ширину.
- **Информационные плашки (Info & Notice Banners):**
  - Рамка: `1px solid #FDE68A` (желтый) или `#C8E6C9` (зеленый).
  - Фон: `#FFFBEB` или `#F0FDF4`.
  - Скругление: `10px`.
  - Отступы: `14px 18px`.
  - Иконка слева: лампочка / инфо-знак / магазин, поясняющий правила сервиса (отсутствие онлайн-оплаты, заказ у одного мастера).

### Таблицы данных (Data Tables)
- **Контейнер таблицы:** фоновый цвет `#FFFFFF`, граница `1px solid #E5E7EB`, скругление `12px`.
- **Заголовок (Thead):** фон `#F9FAFB`, шрифт Inter SemiBold 11px / 12px, цвет `#6B7280`, uppercase, letter-spacing `0.05em`.
- **Строки (Tbody Tr):** высота строки ~`64px`–`72px`, нижняя граница `1px solid #F3F4F6`, отступ ячеек `16px 20px`.
- **Ховер строки:** `#F9FAFB`.

## 4. Сетка, отступы и радиусы (Layout, Spacing & Radii)

### Система отступов (Spacing Scale — 4px / 8px Grid)
- `space-1` = `4px` (микроотступы между иконкой и текстом)
- `space-2` = `8px` (базовые внутренние отступы бейджей, промежутки между чипами)
- `space-3` = `12px` (отступы в компактных карточках)
- `space-4` = `16px` (стандартный отступ внутри полей ввода, паддинги карточек)
- `space-6` = `24px` (отступы между смысловыми блоками, отступы в двухколоночных формах)
- `space-8` = `32px` (дистанция между заголовком страницы и контентной областью)
- `space-12` = `48px` (вертикальный ритм между крупными секциями)
- `space-16` = `64px` (верхний/нижний паддинг hero-блока и футера)

### Контейнер и сетка (Grid & Container)
- **Максимальная ширина контента:** `max-w-7xl` (`1280px`) или `1440px` (с боковыми безопасными отступами `px-6` / `24px` или `px-8` / `32px`).
- **Сетка каталога:** 4 колонки (`grid-cols-4`) с межколоночным интервалом `gap-6` (`24px`).

### Скругления углов (Border Radius)
- `radius-sm` = `4px` (мини-бейджи)
- `radius-md` = `8px` (кнопки, поля ввода, степперы)
- `radius-lg` = `12px` (карточки товаров, блоки таблиц, панели заказов)
- `radius-full` = `9999px` (чипы фильтров, аватары, круглые индикаторы)

## 5. Философия и продуктовые правила (Product Rules)
1. **Без предоплаты и эквайринга:** Интерфейс принципиально исключает ввод номеров карт, CVV и сторонние шлюзы. Онлайн-оплаты нет: оплата по договорённости с мастером при получении заказа.
2. **Правило одного мастера:** В рамках одной корзины заказ формируется строго от одного ремесленника.
3. **Ремесленный фокус:** Отсутствие рейтингов со звездочками и отзывов; ключевой акцент на персоне автора, натуральных материалах и ручном труде.

## 8. Правила для разработки

1. Весь текст на сайте — на русском.
2. Не добавлять функции, которых нет в MVP: онлайн-оплату, отзывы и рейтинги, избранное, чат, уведомления, сортировку каталога, загрузку файлов, корзину из нескольких мастеров.
3. Кнопки действий показывать только тем ролям, которым они разрешены (`docs/architecture.md`, раздел 2).
4. Кнопки смены статуса заказа показывают только разрешённый следующий шаг; для отмены мастером всегда запрашивать причину.
5. Фото товара — по `imageUrl`; если фото нет, показывать серую подложку `#F4F4F2` с названием товара.
